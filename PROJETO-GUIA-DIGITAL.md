# PROJETO -- GUIA DIGITAL DO HÓSPEDE

## ibis Styles Curitiba Centro Cívico

**Versão:** 1.0\
**Tecnologia:** HTML • CSS • JavaScript\
**Hospedagem:** GitHub Pages

------------------------------------------------------------------------

# Objetivo

Criar um Guia Digital moderno, responsivo e intuitivo para hóspedes,
acessado por QR Code e com aparência semelhante a um aplicativo.

------------------------------------------------------------------------

# Público-alvo

-   Hóspedes nacionais
-   Hóspedes internacionais
-   Clientes corporativos
-   Turistas

------------------------------------------------------------------------

# Funcionalidades Gerais

-   Layout responsivo
-   Compatível com celular e computador
-   GitHub Pages
-   QR Code
-   Imagens ampliáveis
-   Vídeos incorporados
-   Botão para WhatsApp
-   Estrutura preparada para PWA
-   Preparado para múltiplos idiomas
